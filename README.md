# Teste Prático

Projeto Java puro, **sem nenhuma dependência externa** (não usa Maven, Gradle ou bibliotecas de terceiros),
desenvolvido para o Teste Prático de Programação da Iniflex.

Desenvolvido com **JDK 21.0.12**.

---

## Como rodar

Na raiz do projeto:

```bash
cd src
javac -encoding UTF-8 *.java
java Principal
```
